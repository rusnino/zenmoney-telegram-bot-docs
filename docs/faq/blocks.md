# Блокировки

!!! warning "Черновик"
    Описывает поведение до живой приёмки записи в ZenMoney; детали могут измениться.

Блокировка означает, что из импорта нельзя записать **ничего**. Коды видны в preview (`Запись невозможна: ...`) и с подробностями в списке «Обработать вручную» (`заблокировано (код): ...`).

| Код | Что значит | Что делать |
|---|---|---|
| `balance_not_verified` | В выписке нет остатков, по которым можно сверить строки (карты Kaspi, часть Halyk/Forte), или остаток вклада не сошёлся из-за процентов. | Проверьте строки сами и нажмите `Баланс не сверен — принять риск`. Это осознанное решение, не «всё ОК». |
| `balance_discontinuity` | Остаток на начало этой выписки не совпадает с остатком на конец соседней, ранее записанной выписки того же счёта. | Проверьте периоды. Если ошибочна старая сохранённая выписка — `/reset_balance KZT 1234 2026-05-01..2026-05-31` (покажет), затем то же с `confirm`, и загрузите заново. Иначе — `принять риск` после проверки строк. |
| `snapshot_malformed` | Часть записей ZenMoney не разобрана и не участвует в поиске дублей. | `/unreadable` → найдите эти записи в ZenMoney по дате, исправьте или удалите → загрузите заново. Принимать риск (`Записи ZenMoney не распознаны — принять риск`) — только понимая, что возможен дубль. |
| `transfer_undecided` | Есть кандидат в перевод без решения. | Решите все карточки (`/transfers`). |
| `file_unparsed` | Один из файлов пакета не разобрался. | Кнопка `Исключить N` убирает этот файл, остальное пересчитывается (возможные половины переводов уйдут во «вручную»). Или отмените и загрузите исправленный файл. |
| `parse_error` | Парсер не смог доказать, что прочитал выписку полностью и верно. Подробность — `код: текст` в списке «вручную». | [Ошибки разбора PDF](pdf-errors.md). Принять риск нельзя. |
| `unmapped_account` | Счёта `банк/IBAN/валюта` нет в `account_map`. | Добавьте запись ([Конфиг счетов](../configuration/accounts.md)), перезапустите бота, загрузите файл заново. |
| `account_absent` | Счёта ZenMoney из `account_map` нет в аккаунте (удалён, опечатка в id). В preview и `/status` есть строка «Счетов из конфига нет в ZenMoney: N». Блокирует весь пакет. | Исправьте `zenmoney_account_id` или верните счёт в ZenMoney, перезапустите бота, загрузите выписку заново. |
| `currency_mismatch` | Счёт ZenMoney в `account_map` не той валюты. | Исправьте `zenmoney_account_id`. |
| `user_unknown`, `user_inconsistent`, `user_unbound` | Счета из `account_map` не принадлежат одному пользователю ZenMoney, или токен поменялся между preview и подтверждением. | Проверьте токен ZenMoney и все `zenmoney_account_id`: один конфиг = один аккаунт ZenMoney. |
| `invalid_external_id` | В ZenMoney есть операция с id не в формате UUID (UUID заглавными буквами, как у iOS, бот принимает). | Найдите и исправьте/удалите её в ZenMoney. Обойти нельзя. |
| `mapping` | Валюты нет в справочнике ZenMoney, нулевая сумма и т. п. | Сохраните время и код, передайте разработчику. |
| `limit` | Операций в пакете больше `ZENBOT_MAX_TX_PER_PLAN` (по умолчанию 2000) или сумма оборотов больше 100 000 000. | Загружайте выписку по месяцам. Лимит операций можно поднять до 5000, лимит оборота — нет. |
| `no_fingerprint`, `bad_fingerprint`, `invariant` | Внутренняя ошибка бота. | Ничего не подтверждать, передать разработчику. |

Кнопка «принять риск» появляется, только если **все** блокировки — из первых трёх строк таблицы и есть что создавать. Для Halyk с автоматически выбранным счётом списания до подтверждения нужна ещё кнопка `Счета списания проверил — продолжить` ([Halyk](../banks.md#halyk)).
