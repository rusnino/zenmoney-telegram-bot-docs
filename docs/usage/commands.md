# Команды бота

!!! warning "Черновик"
    Описывает поведение до живой приёмки записи в ZenMoney; детали могут измениться.

Бот отвечает только владельцу (`OWNER_USER_ID`) и только в личном чате.

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Справка. |
| `/status` | Режим (DRY-RUN или запись), последний импорт из аудит-лога, есть ли неподтверждённый импорт или собираемый пакет. |
| `/history` | Последние 10 импортов: `№ время(UTC) режим статус создано: N`. Статусы — [Аудит-лог](rollback.md#import-statuses). |
| `/export_ids [номер]` | Операции, которые бот отправил в этом импорте (без номера — последний): `id \| дата \| сумма \| валюта \| счёт`. Для [отката](rollback.md#rollback). |
| `/manual` | Список «Обработать вручную» текущего импорта. |
| `/present` | Список «Уже есть в ZenMoney» текущего импорта и по какому признаку найдено совпадение. После рестарта пуст. |
| `/transfers` | Прислать [окно решений по переводам](transfers.md#window) заново внизу чата; у предыдущего окна кнопки снимаются. Если нерешённых кандидатов нет — «Кандидатов в переводы без решения нет.» |
| `/uncategorized [дней]` | Операции ZenMoney без категории за 1–366 дней (по умолчанию 30). Только чтение. Не чаще раза в 20 с. `🤖` — операцию создал бот. Переводы между своими счетами не показываются. |
| `/unreadable` | Записи ZenMoney, которые бот не смог разобрать: дата и последние 4 символа id. |
| `/bank forte\|kaspi\|halyk` | Указать банк, если бот не определил его по файлу. Действует 10 минут и только на **первый файл нового пакета**. `/bank` без аргумента сбрасывает выбор. |
| `/reset_balance <валюта> <4 цифры> [ГГГГ-ММ-ДД..ГГГГ-ММ-ДД] [confirm]` | Забыть сохранённые ботом остатки одного счёта ([`balance_discontinuity`](../faq/blocks.md)). ZenMoney не меняет. Без `confirm` только показывает, сколько будет забыто. |
| `/undo` | Краткая инструкция по ручному откату. Автоматического отката нет. |
