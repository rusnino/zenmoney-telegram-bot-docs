# ZenMoney Telegram Bot

!!! warning "Черновик"
    Описывает поведение до живой приёмки записи в ZenMoney; детали могут измениться.

Telegram-бот, который читает PDF-выписки банков **Forte**, **Kaspi** и **Halyk**, показывает план импорта (preview) и **только после нажатия кнопки «Подтвердить»** создаёт новые операции в ZenMoney. Ещё он ищет операции без категории и предлагает объединять переводы между своими счетами в разных банках (Forte → Kaspi и т. п.).

!!! note "Репозиторий приватный"
    Код бота лежит в приватном репозитории. Этот сайт — для владельца и тех, кому выдан доступ к коду.

## Что бот не делает никогда

- не меняет и не удаляет существующие операции ZenMoney;
- не пишет баланс и не отправляет объекты счетов;
- не угадывает счёт: счёт выписки без записи в конфиге блокирует импорт;
- не объединяет два перевода между своими счетами без вашего решения;
- не повторяет запрос записи сам после сетевой ошибки;
- не создаёт заново операцию, которую он уже записывал, а вы удалили в ZenMoney.

## Как бот защищает запись

- **Dry-run по умолчанию.** Пока не задано `ZENBOT_WRITE_ENABLED=true`, бот ничего не отправляет в ZenMoney: разбор, preview и списки работают, кнопка «Подтвердить» только сообщает, сколько операций было бы создано.
- **Preview и подтверждение.** Запись идёт только после кнопки. Перед отправкой бот ещё раз читает ZenMoney и пересчитывает план; если план изменился, ничего не пишется.
- **Неоднозначное — вручную.** Похожие на существующие операции, нераспознанные строки, неясные переводы бот не создаёт, а показывает списком «Обработать вручную».
- **Тестовый и боевой режимы разделены.** Разные боты в Telegram, токены, конфиги и каталоги данных (`ZENBOT_ENV=test|prod`).
- **Один владелец.** Бот отвечает только одному пользователю Telegram (`OWNER_USER_ID`) и только в личном чате.

!!! info "Автокатегории ZenMoney"
    Бот создаёт операции без категории. ZenMoney может сам проставить категорию, если сервер уже знает получателя (`payee`). Поэтому `/uncategorized` показывает только то, что осталось без категории; категорий бот не ставит.
